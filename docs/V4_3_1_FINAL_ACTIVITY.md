# V4.3.1 — 마지막 체결과 최종 차단 사유 표시

## 종료 직전 체결

기존 실행 순서는 활동 화면 갱신 → 주문 판단/체결 → 종료 조건 확인이었습니다. 종료 대기 중 마지막 매도가 체결되면 다음 화면 갱신 전에 반복문을 빠져나가 마지막 매도 건수·체결표·미확정 주문 표시가 이전 상태로 남을 수 있었습니다.

이제 종료 완료 및 중지 알림 전에 확정된 DB 활동을 다시 게시합니다. 일반 종료, 즉시 정지 모두 현재 확정 내역과 미확정 주문을 구분해 표시합니다. 화면용 DB 조회 실패는 경고로 표시하고 주문 감시나 종료를 중단시키지 않습니다. 초기 화면도 같은 보호된 경로로 읽습니다.

## 매수 금액 차단

전략 BUY 이후 금액·신선도 등의 최종 검사에서 차단되더라도 종목별 진단에 앞선 매수 신호가 남던 문제를 고쳤습니다. 최종 차단 사유, 계산 주문금액, 최소 주문금액, 사용 가능한 원화를 표시하고 기록합니다. 이번 변경은 최소 주문금액에 맞추기 위해 자금 배분을 임의로 올리지 않습니다.

## 검증

마지막 매도 확정 후 종료 알림 전 체결표 갱신, 즉시 정지 시 미확정 주문 보존, 화면 조회 실패 시 종료 완료, 소액 주문 차단 사유/금액 갱신 회귀 테스트를 추가했습니다. 총 145개 테스트와 가상 데이터 화면 검수를 통과했습니다. 진입·청산 기준은 V4.3.0과 같습니다.

V4.3.0의 추가 공개 기록 비교는 [별도 정책 문서](V4_3_ACTIVITY.md)에 있습니다. 1,867개 평가에서 이전 버전 BUY 0회, V4.3.0 BUY 6회였지만 모두 같은 VTHO 종목의 반복 판단입니다. 실제 6건의 주문이나 수익 개선으로 해석할 수 없습니다.
