# V4.3.2 — 후보 교체 조건과 호가 관측 연속성

## 문제

실거래 후보 선택은 기존 후보를 먼저 제거한 뒤 교체 후보를 비교했습니다. 따라서 최소 감시시간이 지난 기존 후보는 점수 차이 조건을 적용하기 전에 사라졌습니다. 기본 교체 차이가 4점이어도 기존 80점이 새 81점 후보로 바뀌는 사례를 재현했습니다.

또한 감시 자리가 남아 있어도 체결이 3초를 넘겨 없으면 구독에서 제외했습니다. 다시 체결이 생겨 복귀할 때는 안전상 이전 호가 기록을 초기화하므로, 잠깐의 체결 공백만으로 지속 수급에 필요한 호가 관측이 반복해서 끊길 수 있었습니다.

## 보완

- 신선한 기존 후보를 비교 시점까지 유지하고 최소 감시시간과 교체 점수 차이를 실제로 적용합니다. 순위 목록에서 잘린 기존 후보도 현재 점수를 확인합니다.
- 신선한 후보를 먼저 배치하고, 남은 자리에서만 직전에 감시하던 잠시 조용한 종목을 관측합니다. 마지막 체결 경과시간이 기존 최소 감시시간(기본 30초)을 넘으면 제외합니다.
- 새 신선 후보가 필요하면 조용한 종목보다 우선합니다. 관리 포지션 감시는 유지하며, 비관리 종목 수는 설정된 한도를 넘지 않습니다.
- 실제 주문의 체결·호가 3초 조건과 모든 진입/청산/비용 제한은 유지합니다. 관측 유지가 곧 매수 허용을 뜻하지 않습니다. 완전히 구독 해제됐다가 복귀한 종목은 계속 호가 기록을 초기화합니다.

## 표시

기존 ‘워밍업 완료’는 기준 이력이 있고 최근 30초 내 체결도 있는 종목 수였습니다. 이력이 이미 쌓였어도 조용하면 수치에서 빠져 워밍업이 초기화된 것처럼 보일 수 있었습니다. 이제 기준 이력을 확보한 수와 그중 최근 30초 체결이 있는 수를 나누어 표시하고 기록합니다.

## 검증 범위

교체 점수 차이, 감시시간, 순위 밖 기존 후보, 일시적 체결 공백에서 호가 이력 보존, 신선 후보 우선, 보존시간 만료, 감시 한도, 관리 포지션 예외를 회귀 테스트로 확인했습니다. 총 154개 테스트와 가상 데이터 화면 검수가 통과했습니다. 관측 연속성의 개선이며 실제 거래 빈도나 수익 증가를 입증하는 결과는 아닙니다. 사용자 계정의 실제 주문은 실행하지 않았습니다.
