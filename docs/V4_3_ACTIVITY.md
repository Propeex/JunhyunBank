# V4.3.0 — 관측 구간 확대와 실제 체결 화면

## 전략

기존 30초 관측 변동폭이 비용 조건에 미달하면 60초, 120초 순으로 과거 절대 수익률의 70% 분위수를 확인합니다. 후보 구간마다 해당 길이 이상의 과거 수익률 표본을 요구하며, 같은 왕복 비용 2배 기준을 만족하는 가장 짧은 구간을 선택합니다. 120초 구간에는 최소 240개 초별 프레임이 필요합니다. 현재 수급, 모멘텀, 호가, 진입 품질, 시장 상태, 전략 건강도 및 실제 주문 유동성 검사는 유지합니다.

보유 기대시간의 하한도 선택된 30/60/120초 관측 구간에 맞춥니다. 예컨대 120초 움직임을 근거로 진입한 뒤 30초에 시간 청산하는 불일치를 방지합니다. 시간 청산은 기대시간의 1.5배 이후 기존 조건을 적용하고, 수급 반전 확인·추적 매도·긴급 손절은 그 전에 작동할 수 있습니다. 손절 폭을 확대하지 않습니다.

관측 변동폭은 미래의 상승이나 순이익 예측이 아닙니다. 긴 구간을 추가하면 진입 빈도와 보유시간, 손익 분포가 바뀔 수 있습니다. 이 구간과 분위수는 장기 수익 최적화 결과가 아니며, 여러 시장 구간에서 별도 검증이 필요합니다.

## 실제 활동 표시

- 날짜별 실제 매수·매도 체결 주문 건수와 이번 실행의 판단 주기 수를 표시합니다. 판단 주기 수는 매수 기회 수가 아닙니다.
- 확인 중인 주문은 실제 체결과 별도로 표시합니다.
- 최근 실제 체결 100건의 확인 시각, 종목, 방향, 가격, 금액, 사유를 표시하고 클릭하면 차트 종목을 선택합니다.
- 차트의 분홍 ▲ 매수, 파랑 ▼ 매도는 DB에 확정된 체결만 표시합니다. 표시 시각은 거래소의 개별 체결 시각이 아니라 프로그램의 체결 확인 시각입니다. 분할 체결은 주문별 가중평균 단가로 표시됩니다.
- 기존 DB 기록을 읽으므로 재시작 후에도 내역이 보존됩니다. LIVE, 양수 체결 수량·가격·금액만 집계하며, 후보 신호·미체결 취소·모의 거래는 체결 수에 포함하지 않습니다.

## 검증

141개 테스트 통과: 30/60/120초 선택과 보유시간 일치, 충분한 과거 표본, 비용 미달, 품질 미달, 즉시 손절, 실제 체결/미확정 주문 분리 및 미체결 취소 제외 등을 포함합니다. 기존 주문 복구와 중복 방지 검사도 통과했습니다.

공개 시세 300초 기록 재생의 1,020개 평가에서 BUY는 기존과 동일한 2회였습니다. 짧은 기록으로 실제 거래 빈도 증가를 확인한 것은 아닙니다. 통제된 테스트에서는 기존 30초 비용 조건에 미달하던 지속 흐름이 긴 구간으로 진입 가능한 것을 확인했습니다.

가상 데이터로 화면과 매수·매도 마커를 렌더링해 검수했습니다. 실제 계좌로 주문하거나 자동매매를 시작하지 않았습니다.
