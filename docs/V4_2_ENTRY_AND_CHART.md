# V4.2.0 — 지속 수급 진입과 시간축 차트

## 진입 정책

기존 호가 품질은 잔량 우위·미세가격 우위·잔량 우위의 증가율 percentile을 곱했습니다. 매수 우위가 유지되어도 증가율이 0이면 품질이 급락했습니다.

이제 최근 10초를 덮는 8개 이상의 초별 호가에서 잔량·미세가격 우위가 모두 양수이고, 관측 간격이 2초 이하이며, 구간 전체와 최근 3개 관측에 걸쳐 잔량 우위가 순감소하지 않았다면 지속 수급으로 인정합니다. 증가율 점수에 잔량·미세가격 percentile 중 낮은 값을 하한으로 사용합니다. 기존 증가형 신호도 유지합니다.

진입 품질 기준, 예상 변동폭 > 왕복 비용의 2배 조건, 최신 시세 검사, 주문 직전 재평가, 자금·유동성 제한을 유지합니다. V4.1의 보유 반전 확인 및 긴급 손절도 유지합니다. 이 변경은 진입 가능한 신호의 범위를 넓히므로 거래 빈도와 손익이 달라질 수 있습니다. 장기 수익성 최적화 결과가 아닙니다.

## 화면

- 차트 종목을 직접 선택하고 고정합니다. 후보 순위가 변해도 종목을 자동으로 바꾸지 않습니다.
- 실제 체결 시각을 시간축으로 표시하고, 5분·15분·1시간을 선택합니다. 프로그램이 수신한 데이터만 표시합니다.
- 초마다 마지막 수신 가격을 보존하고 10초 초과 수신 공백은 선을 끊습니다. 마지막 체결 경과시간도 표시합니다.
- 자산 행을 누르면 해당 차트로 이동합니다. 보유 평균단가를 차트에 표시합니다.
- 보유 코인이 없을 때 원화 대기 상태를 설명합니다. 최근 후보의 시세·비용 대기 건수와 종목별 예상 변동폭·비용·필요 변동폭을 표시합니다.
- 시세 대기는 체결과 호가의 수신 시각을 분리해 보여줍니다. 최근 후보 요약은 누적 거래 확률이나 전체 시장 통계가 아닙니다.

## 검증과 한계

전체 127개 테스트 통과. 지속 우위에서 매수 가능, 짧은 관측·악화·관측 공백 차단, 거래비용 제한 유지 회귀 테스트를 포함합니다. 테스트 주문은 모의 거래소만 사용합니다.

앞서 수집한 공개 시세 300초·8,437개 기록을 재생한 결과 1,020개 평가에서 BUY는 기존처럼 2회였습니다. 이 표본으로 실제 매수 빈도 증가나 수익 개선을 주장할 수 없습니다. 단위 테스트는 이전에 제외하던 지속 수급 사례가 이제 진입 가능함을 확인합니다.

별도 가상 데이터 화면에서 시간축·종목 유지·원화 대기 표시를 렌더링하여 확인했습니다. 실거래 프로그램이나 계정 키는 사용하지 않았습니다.
