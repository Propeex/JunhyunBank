# JunhyunBank

업비트(Upbit) Open API를 이용하는 개인용 자동매매 데스크톱 프로그램입니다.

> ⚠️ **안전 기본값:** 프로그램은 최초 실행 시 `PAPER`(모의매매) 모드로 시작합니다. `LIVE`(실거래)는 사용자가 명시적으로 활성화해야 합니다. 출금 API는 사용하지 않습니다.

## V1 목표

- 업비트 Access Key / Secret Key 최초 입력 및 OS 보안 저장소(keyring) 저장
- PAPER / LIVE 모드 분리
- 시작 / 정상 종료 / 긴급 정지
- KRW 마켓 자동 탐색 및 거래대금 상위 후보 선정
- 5분봉 기반 기본 추세 + RSI 전략
- 주문 전 리스크 관리자 강제 검증
- 일일 최대 손실, 1회 주문 금액, 최대 포지션 수 제한
- 중복 주문 방지 및 클라이언트 주문 식별자 사용
- 보유 자산, 평가금액, 수익률, 후보 종목, 로그, 가격 차트 UI
- SQLite 거래/상태 로그
- 업비트 REST Rate Limit 대응 및 WebSocket 실시간 시세 수집
- 재시작 시 상태 복구 가능한 구조

## 개발 원칙

전략(`strategy`)과 주문/리스크/거래소 연동을 분리하여 이후 V2, V3에서 전략만 반복적으로 교체하거나 확장할 수 있게 합니다.

## 버전 정책

완성 버전은 `V1`, `V2`, `V3` 순으로 GitHub Release를 발행합니다.
